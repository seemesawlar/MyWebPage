# MyWebPage

A polished personal portfolio website for Simisola Oyeniyi, showcasing full-stack software development skills alongside pharmacy and advisory experience.

## Overview

This project is a static HTML/CSS portfolio site built to highlight professional experience, technical skills, and project work. It emphasizes clarity, usability, and a business-focused presentation suitable for employers or recruiters.

## Features

- Responsive layout with modern styling
- Professional summary and experience sections
- Project highlights with portfolio-style descriptions
- Technical skills and certifications
- Clickable social links for GitHub, LinkedIn, and email
- Image hero section with a clean, polished visual design

## Files

- `index.html` – Main portfolio page markup
- `styles.css` – Site styling and responsive layout
- `images/Simisola.JPG` – Profile image used in the hero section

## How to Use

1. Open `index.html` in a web browser to view the portfolio.
2. Edit the content directly in `index.html` to update profile details, experience, or links.
3. Customize styling in `styles.css` for visual changes.

## Deployment

This is a static website, so it can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.
